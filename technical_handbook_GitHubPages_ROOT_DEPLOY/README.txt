SAHAAY Technical Handbook Website

How to use:
1. Extract this ZIP to a folder.
2. Open index.html in Chrome, Edge, Firefox, or Safari.
3. For best use, keep the assets folder beside index.html.

This is a static, offline-friendly website. It includes responsive navigation, section filtering/search, the full handbook text and tables, and four rendered diagrams. No server or internet connection is required.
